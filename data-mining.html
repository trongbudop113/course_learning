Học để làm gì?

Data Mining không chỉ chạy thuật toán. Mục tiêu là biến dữ liệu thành quyết định có căn cứ, biết kiểm tra bias, leakage, overfitting và chất lượng dữ liệu.

01

Hiểu dữ liệu

Đọc schema, kiểu dữ liệu, missing values, outliers, distribution và quan hệ giữa biến.

02

Chọn kỹ thuật

Biết khi nào dùng clustering, classification, association rules, anomaly detection hoặc dimensionality reduction.

03

Đánh giá đúng

Không chỉ nhìn accuracy. Dùng metric phù hợp, validation rõ ràng, giải thích được kết quả cho người dùng.

Lộ trình 10 tuần

Mỗi chặng có output rõ ràng. Học xong là có portfolio gồm notebook, báo cáo insight và mô hình được đánh giá.

W1

Nền tảng dữ liệu

  • Ôn Python, pandas, numpy, notebook workflow.
  • Đọc CSV/JSON, hiểu dataframe, schema, data dictionary.
  • Output: data profiling report cho một dataset nhỏ.
W2

Làm sạch dữ liệu

  • Missing values, duplicate, type conversion, outlier handling.
  • Quyết định giữ/xóa/sửa dữ liệu phải có lý do.
  • Output: cleaning log và before/after quality summary.
W3

EDA và trực quan hóa

  • Distribution, correlation, group comparison, time trend.
  • Biết đặt câu hỏi phân tích trước khi vẽ chart.
  • Output: 6 chart + 5 insight có bằng chứng.
W4

Feature engineering

  • Encoding category, scaling, binning, date features, text features cơ bản.
  • Tránh data leakage khi tạo feature.
  • Output: feature table và giải thích business meaning.
W5

Clustering

  • K-means, hierarchical clustering, chọn số cụm, silhouette score.
  • Ứng dụng: customer segmentation hoặc nhóm hành vi học tập.
  • Output: cluster profile và khuyến nghị hành động.
W6

Classification

  • Train/test split, logistic regression, decision tree, random forest.
  • Metric: precision, recall, F1, confusion matrix, ROC-AUC.
  • Output: baseline model và model card ngắn.
W7

Association rules

  • Apriori/FP-growth, support, confidence, lift.
  • Ứng dụng: market basket, lesson recommendation, combo course.
  • Output: top rules và giải thích rule nào đáng dùng.
W8

Anomaly và giảm chiều

  • Isolation forest, z-score/IQR, PCA/t-SNE/UMAP ở mức ứng dụng.
  • Biết phân biệt anomaly thật và lỗi dữ liệu.
  • Output: anomaly review table và visualization.
W9

Evaluation và explainability

  • Cross-validation, error analysis, feature importance, model limitation.
  • Kiểm tra imbalance, bias, drift và reproducibility.
  • Output: evaluation report đủ để reviewer kiểm tra.
W10

Capstone

  • Chọn một dataset thật, đặt câu hỏi, làm pipeline end-to-end.
  • Nộp notebook, slide/report, model card và recommendation.
  • Output: portfolio project hoàn chỉnh.

Bài học tích hợp

Mỗi bài có mục tiêu, kiến thức chính và bài tập thực hành. Bạn có thể làm bằng Python notebook hoặc lưu mô tả vào DB hiện có.

01

Data profiling

Học cách đọc dataset trước khi xử lý: rows, columns, dtype, missing, duplicate, cardinality.

  • Thực hành: tạo profile cho Titanic hoặc Student Performance.
  • Nộp: bảng vấn đề dữ liệu và 5 câu hỏi phân tích.
02

Cleaning pipeline

Xây pipeline làm sạch có log, không sửa dữ liệu tùy tiện.

  • Thực hành: xử lý missing age, category sai, outlier numeric.
  • Nộp: cleaning decision table.
03

EDA story

Biến chart thành insight. Mỗi chart phải trả lời một câu hỏi.

  • Thực hành: so sánh nhóm, trend, correlation và distribution.
  • Nộp: 6 chart + insight + caveat.
04

Segmentation

Phân nhóm người dùng/khách hàng và đặt tên cụm theo hành vi.

  • Thực hành: K-means customer segmentation.
  • Nộp: cluster profile và action recommendation.
05

Classification baseline

Tạo model baseline và đánh giá metric phù hợp với bài toán.

  • Thực hành: predict churn, pass/fail hoặc fraud flag.
  • Nộp: confusion matrix, F1, error analysis.
06

Association rules

Tìm luật kết hợp giữa item, khóa học, bài học hoặc hành vi.

  • Thực hành: basket rules với support/confidence/lift.
  • Nộp: top 10 rules và rule đáng hành động.
